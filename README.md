# Simple C To-Do List

A command-line to-do list application written in C using basic 2D arrays and user-defined functions.

## Features
- View current tasks
- Add new tasks
- Complete and remove tasks automatically shifting subsequent items
- Simple menu-driven interface

## How to Compile and Run
1. Open a terminal in the project directory.
2. Compile using GCC:
   ```bash
   gcc todo.c -o todo
